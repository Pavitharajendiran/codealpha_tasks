# E-Commerce Store

A full-stack e-commerce website where users can browse products,
add products to cart, and place orders.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Features

- View products
- Add products to cart
- Shopping cart management
- Place orders
- MongoDB database integration
- REST API

## Project Structure

- `backend/` - Server-side code and APIs
- `frontend/` - User interface
- `models/` - Database models
- `routes/` - API routes

## How to Run

1. Clone the repository
2. Install dependencies
3. Start MongoDB
4. Run the backend server
5. Open the frontend
